0. Opsæt en agent

En kodeagent er en AI, der ikke bare svarer på spørgsmål - den handler i din kodebase. Den læser filer, skriver kode, kører kommandoer og bliver ved, til opgaven er løst. Tænk på det som en junior praktikant med adgang til din terminal, frem for en chatbot.

I praksis er det en AI-model koblet med et harness - almindelig kode der opdeler opgaver og omsætter modellens kapacitet til konkrete handlinger.

Denne serie bruger Claude Code, Anthropics CLI-agent. Andre muligheder findes (Cursor, Copilot, Opencode, Aider), men Claude Code er det, vi holder os til.

Analogi - Agent

  • AI (LLM'er) er som en hest - rå, utæmmet kraft.
  • En agent er som et seletøj - det lader os styre den kraften og bruge den til noget nyttigt.
  • I praksis er AI'en en stor maskinlæringsmodel trænret på data med tilfældighed indlejret, og seletøjet er almindelig deterministisk kode, der styrer modellen.

Priser

Priserne ændrer sig - tjek Anthropics prisside for aktuelle tal.

Der er to måder at betale på: Plans og API-nøgler. Med Plans betaler du en fast månedlig pris og får et forbrug, der nulstilles periodisk. API-nøgler koster ingenting at have - du betaler kun for det, du bruger.

Se dit aktuelle forbrug med /usage-kommandoen.

Til privatbrug eller for enkeltpersoner i en virksomhed anbefaler jeg Plans - forudsigeligt forbrug og ingen overraskelser. API-nøgler giver mening i produkt- eller projektsammenhæng, hvor man vil styre omkostningerne præcist.

Analogi - priser

  • Plans: En ven låner dig en bil for 20 $/måneden. Den har et benzinkort med dag-, uge- og månedslofter. Du betaler selv i ferien, men du ved altid hvad det koster.
  • API-nøgler: Vennen låner dig bilen gratis, men du betaler selv benzinen. Bruger du den ikke, koster den ingenting - men sætter du den på selvkørende tilstand og lader den løbe, kan det løbe op.

Hent Claude Code

Ikke fortrolig med terminalen? Hent Claude Code desktop-appen - det er den nemmeste start.

  1. Opret en konto på claude.ai - du skal have et betalt abonnement (Pro eller derover) for at bruge Claude Code.
  2. Installér CLI'en: npm install -g @anthropic-ai/claude-code
  3. Åbn en terminal i din projektmappe og kør: claude

Det er det hele. Herfra fungerer det som en chat - skriv hvad du vil have lavet, fx "skriv et haiku om træer" eller "lav en Python-funktion der konverterer Celsius til Fahrenheit".

Grundlæggende styring

Du bestemmer. Agenten har læseadgang til dit repo, men beder om lov, hver gang den vil ændre noget.

  • ESC eller ctrl+c stopper eksekveringen midtvejs.
  • To tryk på ctrl+c afslutter Claude Code.
  • To gange ESC spoler tilbage til et tidligere punkt i samtalen.
  • /usage viser dit aktuelle forbrug.
  • /clear eller /new nulstiller kontekstvinduet.

Hvad nu

Næste indlæg handler om den grundlæggende arbejdsgang: filer som input, filer som output, og prompts der gemmes i stedet for at gå tabt. Det er der, det rigtige produktivitetsspring sker.

Appendiks - installation af VS Code og npm

VS Code

Hent installationsprogrammet fra den officielle VS Code-side og kør det. Vælg dit OS (Windows, macOS eller Linux) - det er en helt normal installation.

Terminalvinduet i VS Code

Claude Code kører i en terminal. VS Code har en indbygget:

  • Tryk Ctrl+` for at slå den til og fra
  • Eller gå til Terminal -> Ny terminal i menulinjen

Terminalen åbnes nederst i editoren, allerede rettet mod din projektmappe. Det er her du kører claude.

npm

npm følger med Node.js - installér Node, og du har npm.

Hent LTS-versionen fra nodejs.org/en/download, kør installationsprogrammet, og tjek bagefter i terminalen:

node -v
npm -v

Begge skal vise et versionsnummer. Så er du klar til npm install -g @anthropic-ai/claude-code.
