TL;DR — npm install -g @anthropic/claude-code → claude login → claude. ESC for at stoppe, ctrl+c to gange for at afslutte, /usage for at tjekke forbrug. /clear eller /new for at rydde kontekst. Priser: brug Plans til personlig brug, API-nøgler til produkter.

Hvis du allerede har Claude Code (eller ligende) installeret og kørende, kan du springe til Indlæg 1.

0. Opsæt en agent

En kode agent er en AI, der ikke bare besvarer spørgsmål — den udfører handlinger i din kodebase. Den læser filer, skriver kode, kører kommandoer og itererer, indtil opgaven er løst. Tænk på det mindre som en chatbot og mere som en junior praktikant, der sidder ved din terminal.

I praksis er det en LLM-model (AI) + et harness (almindelig kode), der hjælper med at opdele opgaver og udføre handlinger ved hjælp af LLM'ernes "tænke"-evne.

Denne serie fokuserer på Claude Code, Anthropics CLI-agent. Der findes andre muligheder (Cursor, Copilot, Opencode, Aider), men Claude Code er det, vi bruger gennem hele serien.

Hent Claude Code

Ikke fortrolig med CLI? Download Claude Code desktop-appen — det er den nemmeste måde at komme i gang på.

  1. Opret en konto på claude.ai — du skal have et betalt abonnement (Pro eller derover) for at bruge Claude Code meningsfuldt.
  2. Installér CLI'en: npm install -g @anthropic-ai/claude-code
  3. Åbn en terminal i din projektmappe og kør: claude

Det er indgangspunktet.

Det minder om en chat, og du kan skrive enhver anmodning som "skriv mig et haiku-digt om træer" eller "lav mig en Python-funktion til at konvertere Celsius til Fahrenheit"

Grundlæggende styring

Du styrer agenten. Den har læseadgang til det repo, du startede den i, men beder dig om godkendelse til alle ændringer, hvor den kører kommandoer.

  • du kan stoppe eksekveringen midtvejs med ESC eller ctrl+c.
  • du afslutter ved at trykke ctrl+c to gange.
  • ved at trykke esc to gange kan du spole tilbage til et tidligere punkt i samtalen.
  • /-kommandoer lader dig udføre kommandoer, som /usage, der viser dit aktuelle forbrug.
  • /clear eller /new for at nulstille kontekstvinduet.

Priser

Priserne ændrer sig — tjek Anthropics prisside for aktuelle tal.

Bemærk, at der er to faktureringsmetoder. Plans og api-nøgler. Plans giver grænser, der nulstilles periodisk. Du betaler en månedlig pris — også selvom du aldrig bruger det. api-nøgler betaler baseret på token-forbrug.

Se dit forbrug ved at køre /usage-kommandoen eller besøg x-siden.

Til privat eller virksomhedsmæssig individuel brug vil jeg anbefale Plans med forudsigelige udgifter, og kun bruge api-nøgler i produkt- eller projektsammenhæng.
