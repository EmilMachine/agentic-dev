My Opinionated Claude Code Setup

I want a setup that is A) Agent framework agnostics B) flexible to accomodate most proejcts.

Outline

  1. Agent Agnostics
  • AGENTS.md - main entry point to agents
    • refence other files instead of having the full context itsef mainly located in an AGENTS folder
    • Note AGENTS.md is read on EVERY agent startup, so I want it short, as an index where to find more knowledge.
  • AGENETS/{topic}.md
    • each .md file hold relevant context for a topic, so any given agent can read only the relevant parts.
  • Code agent reference points
    • points to AGENTS.md (main index / entry point)
    • e.g. CLAUDE.md, opencode.json points to AGENTS.md (could maybe be symlinks but actual files are more robust.)
  1. flexible setups.

  • folders:

    • myprompts
    • myreports

  • Each have a .gitignore * file

  • The prompts are mainly for input / iteration in prompts input.

  • myreports are for largely single turn analysis .md files like codereview, cleanup suggestions

  • the “my..” + .gitignore * is easily extenable to whatever folder you need.

    • It indicates it is messy mid-way artifacts useful for local work.
    • Important things should be distilled and end up as clean artifacts in code, AGENTS/ folder, README.md, changelogs etc.

/codereview <branch> — Review a branch

Fetches the diff between a branch and main, then writes a terse major/minor/nit review to myreports/. Good before opening a PR, or to highlight were to look in a review. Will try to pull from remote first and fallback to local compare.

/cleanup [path] — Find dead code

Scans a path for dead code, unused tests, redundant logic, and outdated docs. Writes a report to myreports/. Defaults to the current directory.

Note it does not do the cleanup. It writes the report suggesting the cleanup.

/secure [path] — Security audit

Runs OWASP Top 10 checks, secrets scanning, and dependency CVE checks. Writes a severity-ranked report to myreports/.

Note this is a bit of quick stopgap for hobby projects. I would recommend real projects put these checks more structured as part of CICD.

/setup [path] — Bootstrap agent config

Creates AGENTS.md, CLAUDE.md, AGENTS folder and private prompt dirs in a project. Idempotent — safe to run on an existing project.
