What Is a Coding Agent?

A coding agent is an AI that doesn’t just answer questions — it takes actions in your codebase. It reads files, writes code, runs commands, and iterates until a task is done. Think of it less like a chatbot and more like a junior intern sitting at your terminal.

In practice it is LLM model (AI) + a harness (regular code) to help split tasks, take actions into the “thinking” power of LLMs.

This series focuses on Claude Code, Anthropic’s CLI agent. Other options exist (Cursor, Copilot, Opencode, Aider), but Claude Code is what we’ll use throughout.

Getting Claude Code

  1. Sign up at claude.ai — you need a paid plan (Pro or above) to use Claude Code meaningfully.
  2. Install the CLI: npm install -g @anthropic/claude-code
  3. Authenticate: claude login
  4. Open a terminal in your project folder and run: claude

That’s the entry point.

It is similar to a chat, and you can write any request like “write me a haiku poem about trees” or “make me a python function to convert celcius to farenheit”

Basic controls

You control the agent. It has reading access to the repo you started it in, but ask you for all changes were it will run commands. - you can stop execution midway with ESC or ctl+c.  - you exit by pressing ctl+c twice. - pressing esc twice allow you to rewind to an earlier point in the conversation. - / commands allow you execute commands, like /usage that will show you current usage. - /clear or /new to reset context window.

Pricing

Pricing changes — check the Anthropic pricing page for current numbers.

Note there is two billing methods. Plans and api-keys. Plans gets limits that resets periodically. You pay a monthly fee - even if you never use it. api-keys pays based on token usage.

See usage by running the /usage command or visit x page.

For private or coorperate individual use I would recommend plans with predictiable spend, and only use api-keys in product or project setting.
