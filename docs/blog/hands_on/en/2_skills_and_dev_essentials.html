Skills: What They Are and How to Use Dev-Essentials

Claude Code has a skill system — slash commands that extend what the agent can do. This post shows what skills are and walks through three from the dev-essentials pack that I created.

buodl

What is a skill?

A skill is a reusable prompt, packaged as a slash command. It is similar to refercing a file with the prompt text, but easier accessible and sharable. When you type /procon3, Claude executes a structured decision-making prompt. you get a shortcut to call a prompt template. Like function it cal also take arguments, after the skill.

Skills live in .claude/skills/ in your repo (or globally in ~/.claude/skills/). They're just markdown files — readable, editable, version-controllable.

Installing dev-essentials

Inside a Claude Code session, add the skillhub marketplace and install the plugin:

/plugin marketplace add https://github.com/EmilMachine/skillhub
/plugin install dev-essentials

That's it. The skills are now available as slash commands in any project.

To update later:

/skillhub-update

Skills worth knowing

/procon3 (or /pc3) — Pick between options

Use it when you're choosing between two or more approaches and want structured reasoning:

/pc3 should we use zod or yup for schema validation in this project?

Returns 3 alternatives, each with pros and cons. It can also be trouble shooting /pc3 is a shortcut alias for /procon3.

Can also work like a mini planning session. If you just ask what is the best ways to do X, claude can easily propose a solution and start implementing it without you approving. Outlining 3 gives a clear wait for user input signal, and also highligts the tradeoffs in making the decision.

/skillhub-update — Keep plugins current

Detects installed plugins, diffs versions, and updates anything stale. Run it periodically or after pulling the repo.

Note: Skill names and behaviors can change between versions. These reflect the current state — check the source if something behaves differently.

/issue — Report a problem with a Skillhub skill.

Describe a bug with a skillhub skill and create a github issue based on previous interactions. Can be used just as \issue or \issue <your summary of problem>

Note the skill useses the previous context populate the issue and tries to avoid leaking project specifics or secrets like emails.

It will try to automatically create the issue using the github issue
